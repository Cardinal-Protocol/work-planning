Scope, in one breath

Ship YieldPerpVault + YieldPerpSettlement, the off-chain pricing/accrual/funding engine, and a competition trading UI — all against a governance fee table (baseSpreadBps / hedgeCostBps / riskLoadBps, per leverage rung) that admins can update live.

  • Treated as an external input, not built here: Andrew/Re7's Model v1.2 quoting engine and its INTERFACE-fee-table-v1.md output — already walk-forward validated (gates 1–2 passed, 2026-09-02). Our job is to ingest and admin-update that table, not re-derive it.
  • Carried over as cut, unchanged: hedge-routing tiers, generated coefficient tables, ≥1000× rungs, multisig operator, fraud proofs, LP withdrawal cooldown. Same reasoning as the source doc's cut-list — testnet stakes, manual prize payout.
  • New since the last iteration: the funding-fee model adopts Model v1.2's carry-forward settlement (one epochQuantum per boundary, remainder carried) and entry-crossing-once rule — the fix for the "chunky funding charge" complaint.
  • Frontend framing: a real trading UI (open/close/top-up/re-center, dashboard, leaderboard, faucet) sized for a testnet competition, not production polish — no cross-device/accessibility hardening pass.

Watch these four

  • Contracts pace is the whole schedule. If Steve's hours slip toward the 5 hr/wk floor, the finish date moves by roughly one week per week of slippage below the 7.5 hr/wk baseline — there's no slack elsewhere to absorb it.
  • Frontend has one owner and it's already the busier person. Leifu doing backend then frontend sequentially is what makes 84 hrs of frontend land in the same window as contracts. Splitting frontend to a third person from Wk3 onward would pull the whole project in by ~3–4 weeks instead.
  • Two freezes gate everything and both are due Week 1: the EIP-712 intent/Quote structs (Settlement + Intent Executor both build against them) and the fee-table field schema (fee-table storage, ingestion tool, and the admin API all build against it). A change after Wk2 forces rework on both tracks it touches.
  • Admin close-out and margin-exhaustion close are still open TODOs in the source doc's Closing section — they need to be added to the signed-intents list and confirmed as contract-accepted before Settlement's intent set is finalized in Wk1–2, or Task A2 gets reopened later.
